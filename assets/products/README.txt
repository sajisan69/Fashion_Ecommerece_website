HOW TO ADD A PRODUCT
1. Create a new folder here, e.g.  assets/products/black-hoodie
2. Put 3-4 photos inside named 1.jpg, 2.jpg, 3.jpg, 4.jpg  (1.jpg is the cover photo). Portrait 4:5 (e.g. 800x1000) looks best.
3. Open data/products.json, copy one product block and change id, name, price and the image paths.
The website updates automatically.
